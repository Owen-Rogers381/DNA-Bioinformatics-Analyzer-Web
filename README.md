# BioLab — Go API + SQLite

веб-приложение для анализа ДНК.

## Запуск
Требуется Go 1.22+ и доступ к интернету при первом скачивании зависимости SQLite.

```bash
go mod tidy
go run .
```

Откройте http://localhost:8080

SQLite-файл `biolab.db` создаётся автоматически рядом с приложением. Путь можно изменить переменной `BIOLAB_DB`.

## API

- `GET /api/health` — проверка сервера.
- `POST /api/analyze` — анализ и сохранение результата.
  ```json
  {"sequence":"ATGAGTAAAGGAGAAGAACTTTTCACTGGAGTTGTCCCAATTCTTGTTGAATTAGATGGT"}
  ```
- `GET /api/history` — последние 50 анализов.

### Реализация
- Проверка входных символов: разрешены A/T/G/C, пробелы и переводы строк игнорируются.
- Подсчёт A/T/G/C и GC%.
- Обратная комплементарная цепь, транскрипция в мРНК и трансляция по стандартному генетическому коду.
- Поиск первой ORF: первый `ATG`, затем стоп-кодон в той же рамке. Координаты 1-based и включают стоп-кодон.
- SQLite хранит исходную последовательность, вычисленные показатели и время анализа.

Трансляция `protein` начинается с первого нуклеотида последовательности и не ищет стартовый кодон отдельно; поле ORF вычисляется независимо. Это учебный прототип, не медицинский/клинический инструмент.
